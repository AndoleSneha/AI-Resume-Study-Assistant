# AI-Powered Resume & Study Assistant

An AI-powered Resume and Study Assistant built using Python, LangChain,
FAISS, Sentence Transformers, and Large Language Models.

## Features

- Resume and PDF document processing
- Text chunking
- Semantic search using FAISS
- Sentence Transformer embeddings
- Retrieval-Augmented Generation (RAG)
- LLM-based question answering
- Interactive user interface
- Voice-based interaction

## Technologies Used

- Python
- LangChain
- FAISS
- Sentence Transformers
- Groq
- Gradio
- RAG Architecture

## Architecture

Documents → Text Extraction → Text Chunking → Embeddings → FAISS Vector Store
→ Relevant Document Retrieval → LLM → Generated Response

## How to Run

1. Clone this repository.
2. Install the required dependencies.
3. Configure the required API keys using environment variables.
4. Open the Jupyter Notebook.
5. Run the notebook cells sequentially.

## Security

API keys and secret credentials are not included in this repository.
